# Шаблон проекта — BE-U1000 на отладочной плате EVU-BA-2.1

Собирается как есть — проверено сборкой в четырёх сочетаниях (`--full`/`--minimal` ×
eFlash/TCM) и **прогнан на плате 2026-08-31**: светодиод, консоль, меню, импульс,
захват через перемычку и АЦП. Из него извлечён каждый блок кода в
[`../reference/recipes.md`](../reference/recipes.md); он же отвечает на вопрос
«как это на самом деле подключено на этой плате».

## Развернуть

```sh
variants/new-project.sh ~/путь/к/Проекту            # полный вариант
variants/new-project.sh ~/путь/к/Проекту --minimal  # только мигалка
cd ~/путь/к/Проекту && make BAIKAL_SDK=$HOME/путь/к/SDK_2_1
```

Проба без стирания eFlash — сборка под TCM. Область данных при этом задавать
**явно**: у DMA нет доступа к TCM, и АЦП молча перестанет отдавать результат.

```sh
make clean BAIKAL_SDK=...
MEM_REG_ROM=TCMA MEM_REG_RAM=SRAM make BAIKAL_SDK=...   # ⚠ RAM именно SRAM
```

Копирование дерева руками даёт то же самое: ничего не генерируется, абсолютных
путей нет, имя проекта нигде не зашито — оно берётся из имени каталога, и от
него же зависит имя образа (`output/debug/<каталог>.bin`).

Прошивка — раздел «Прошивка» в `SKILL.md`. Кратко: перемычки XP1 в `UART`
(установлена только `M0`), кабель в XS2, дальше BootROM CLI по UART0.

## Что в каждом варианте

| | `--minimal` | `--full` |
|---|---|---|
| Флеш-память | **8 484 Б** (3,2 % от 256 КБ) | **25 536 Б** (9,7 %) |
| ОЗУ | 424 Б | 536 Б |
| Светодиод LD1 (`PC0`, активен высоким) | ✅ | ✅ |
| Кнопка SB1 (`PC13`, нажата = ноль) | — | ✅ |
| Консоль UART0 115200, **своя, не BootROM** | — | ✅ |
| Временная база TIM0 + CLIC, 64 разряда | — | ✅ |
| Захват фронта, PWMA1 канал 0 (`PB8`) | — | ✅ |
| Импульс заданной ширины, PWMA2 канал 0 (`PC5`) | — | ✅ |
| Аналоговые входы, ADC0 + DMA0, 4 канала | — | ✅ |

Измерено на плате 2026-08-31 (образ в TCM, данные в SRAM): группа из четырёх
каналов АЦП — **66 мкс**; каждый импульс, выданный командой `p`, ловится
захватом ровно один раз; тактовые CCLK/PCLK0/1/2/HCLK — 25 МГц.

Цифры измерены сборкой под eFlash (`make`). Тот же полный образ под TCM
занимает 39,0 % от 64 КБ области TCMA.

## Что делает полный вариант

Печатает в UART0 меню и ждёт команду:

```
h — помощь            l — переключить LD1
p — выдать импульс    a — снять аналоговые входы
c — статистика захвата (обнуление — C)
s — состояние: тактовые частоты, база, окно планирования
```

**Импульс и захват проверяются без внешнего генератора:** перемычка
`PC5` (XP8 контакт 6) → `PB8` (XP10 контакт 13) замыкает выход на вход. Блоки
при этом разные — PWMA2 и PWMA1, — поэтому измерение не зависит от
измеряемого. Без перемычки команда `p` всё равно работает, просто счётчик
захвата не растёт.

## Файлы по подсистемам

| Файл | Подсистема | Нужен для |
|---|---|---|
| `Makefile` | сборка | обоих вариантов |
| `include/board.h` | привязка к плате | обоих; **это тот файл, который переносится в следующий проект** |
| `src/app.c` | прикладной цикл и меню | обоих (в `--minimal` заменяется на `variants/minimal/app.c`) |
| `src/console.c`, `include/console.h` | вывод `printf` и приём опросом | `--full` |
| `src/timebase.c`, `include/timebase.h` | время на TIM0 через прерывание | `--full` |
| `src/capture.c`, `include/capture.h` | захват фронта на PWMA1 | `--full` |
| `src/evout.c`, `include/evout.h` | импульс двумя совпадениями на PWMA2 | `--full` |
| `src/adc_dma.c`, `include/adc_dma.h` | группа каналов АЦП через DMA | `--full` |
| `variants/` | сценарий развёртывания и минимальный `app.c` | в развёрнутый проект не попадает |

Подсистемы независимы: снять любую из полного варианта — удалить пару файлов и
вызовы из `src/app.c`. Общее у всех одно — `board.h` и временная база
(`capture` и `evout` берут по ней метки).

## Почему точка входа лежит в `app.c`, а не в `main.c`

Makefile подключает `Projects/_template/syscalls.c` из SDK, а рядом с ним в
SDK лежит свой `main.c`. При совпадении имён объектных файлов в сборку попадает
не тот, который ожидался. Имя `app.c` снимает вопрос целиком.

## Стороннего кода в шаблоне нет

Всё внешнее берётся из SDK по пути `$(BAIKAL_SDK)` и сюда не копируется:
модули HAL (`bmcu_cru`, `bmcu_gpio`, `bmcu_uart`, `bmcu_tim`, `bmcu_pwma`,
`bmcu_adc`, `bmcu_dma`), BSP платы (`BSP/EVU_BA_2_1`) и заглушки системных
вызовов (`Projects/_template/syscalls.c`). Лицензия на них — в LICENSE самого
SDK.
